Print

Printing is locked by safe mode

Start, pause, resume, and stop are turned off so nothing moves by accident.

To unlock, set "BAMBU_SAFE_MODE": "0" in ~/.cursor/mcp.json yourself, then restart this page with npm run ui.

Can't reach the printer?

macOS must allow the app that started this page to reach devices on your home network.

  1. Open System Settings → Privacy & Security → Local Network.
  2. Turn on Cursor. If you ran npm run ui from the Terminal app, turn on Terminal instead.
  3. Quit that app fully with Cmd+Q and reopen it. A window reload is not enough.
  4. If the app is missing from the list, reopen it, try once, and click Allow on the macOS prompt.

Also check that the printer is on, on the same Wi-Fi, and has LAN Only turned on in its settings.
